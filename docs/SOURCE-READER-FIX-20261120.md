# Source reader correction — 20 November 2026

Successful HTTP downloads were being classified as inaccessible when publishers put prose outside `main/article`, in sibling title/body containers, or in publisher JSON hydration. The correction reads bounded, same-page article scopes and publisher `body_html` without executing JavaScript. Canonical identity, matching visible headline, scope uniqueness, and structured article identity are checked. Actual HTTP 403 remains inaccessible; no access restriction is bypassed. HTTP/network failures are distinguished from an unrecognized article layout.

Evidence comparison now protects quoted sentence boundaries and name/US abbreviations. It removes URLs, complete courtesy sentences, and repeated speech stutters only from its comparison text. The complete original input still goes to DistilBERT–LR and remains in Text checked. Reported assertions and literal attributed quotes can be compared with article prose. Short transcript quote echoes require an already supported reported factual unit, source attribution, matching meaningful terms and polarity; new facts must be established independently. Caption/audio agreement alone cannot establish truth.

The unchanged classifier is `suriph-finetune-6a35c6d4a2a0`, threshold 0.85. No classifier training, dataset edits, encoder changes, private configuration changes or extension changes were made. The ordinary NLI acceptance cutoffs remain 0.998 support and 0.999 contradiction. Explicit English reported statements have a separate 0.90 entailment cutoff, restricted by syntax and material-anchor validation. This is an evidence-relation score, not final-result confidence or factual accuracy.
